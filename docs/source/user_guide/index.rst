User guide
==========

The :doc:`../quickstart` gets one match on screen fast. This is the full
tour -- every piece of the pipeline, one topic per page, in the order
you'd normally reach for them: load data in, pull metrics out, layer on
a value model and ratings, describe *how* a restart was taken, flip to
the defending side, aggregate a season, then export and plot the result.

Already know which set-piece type you care about? :doc:`../categories`
answers "what can I get for a corner / free kick / throw-in / penalty /
goal kick / kick-off" directly, with links back into these pages for the
detail.
